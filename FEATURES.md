### Frontend
- Next.js 14 (App Router)
- TypeScript
- TailwindCSS
- ShadCN UI Components
- React Query (Data Fetching)
- Framer Motion (Animations)
- React Hook Form (Forms)
- Zod (Validation)

- NestJS Framework
- TypeScript
- PostgreSQL Database
- Direct SQL Queries with Supabase
- JWT Authentication
- Cloudinary (File Storage)
- Razorpay (Payments)
- Nodemailer (Emails)

### Database Schema
- Users Table
- Cars Table

- Blogs Table
- Search Analytics Table
- Coupons Table
